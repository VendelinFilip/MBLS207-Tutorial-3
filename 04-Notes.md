
# 4 Notes if you have trouble with `make`

```bash
# If ’make’ complains about not finding a library called
# zlib, you try running the following command:
sudo apt - get install zlib1g - dev

# If ’make’ complains about not finding "gcc" (or "CC")
# or "g++", try running the following:
apt - get update
sudo apt - get install gcc
sudo apt - get install g++
```
