## Exercise 2

Look up the classic PAM250 and BLOSUM62 matrices for scoring amino acid substitutions. Which substitution is more probable for either matrix, W ↔ F or H ↔ R? What about D ↔ E, and D ↔ K? Explain these results, and use a biological perspective to interpret them.

## Exercise 3

*Sequence1* `VWEDNWDDD`

*Sequence2* `VSEDNRDDD`

*Sequence3* `VWDDNWDED`

1. Calculate pairwise alignment scores between all the sequences using the identity matrix (matches=1; mismatches=0). Is Sequence1 more similar to Sequence2 or to Sequence3? What would happen if you would use the identity matrix with match/mismatch scores of 2/0 instead of 1/0?
2. Calculate pairwise alignment scores between all the sequences using the BLOSUM62 matrix. Is Sequence1 more similar to Sequence2 or to Sequence3?
3. Which of these substitution matrices gives you the most biologically meaningful similarity score? Explain why.
